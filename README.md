# SOCFlow

SOCFlow is a cybersecurity learning platform designed to help Security Operations Center (SOC) analysts investigate and respond to security alerts through structured playbooks and investigation methodologies.

---

## Features

- Incident Response Playbooks
- Step-by-Step Investigation Methodology
- Alert Triage Guidance
- Blue Team Focused Content
- Searchable Playbook Library
- Responsive User Interface
- Practical SOC Investigation Workflows

---

## Available Playbooks

- SQL Injection Detected
- Suspicious PowerShell Script Executed
- CVE-XXXX-XXXXX Exploitation Detected
- Persistence Mechanism Detection
- Brute Force Attack
- Suspicious VPN Login
- Command and Control (C2) Traffic

---

## Purpose

SOCFlow was created to provide a centralized collection of SOC investigation playbooks that help analysts understand:

- What to investigate
- Where to look
- What evidence to collect
- How to determine impact
- How to respond effectively

The platform is designed for students, aspiring SOC analysts, and cybersecurity professionals who want a structured approach to security investigations.
